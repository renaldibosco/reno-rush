# Reno Rush

An open-world 3D city game that runs in the browser on phones and PCs. Built with [three.js](https://threejs.org/), all in one `index.html`.

**Play:** https://renaldibosco.github.io/reno-rush/ (once GitHub Pages is switched on)

## What you can do
- Drive the red #49 around a mapped town with 81 named streets, traffic that keeps left, and 12 gold rings to find
- Get out and walk, run, jump and climb walls onto rooftops
- Take any car, van, auto, lorry, ambulance or the school bus
- Crash and dent your car; at zero health you have 15 seconds to get out before it explodes
- Reno Pit Shop: repair, paint, rims, tyres, engine stages, spoiler, stripes and race number
- Walk into City Bank, City Hospital, St. Mary's Church and Fuel Mart
- Chat with groups of friends around town
- Five music tracks, graphics and control settings

## Controls
| Action | Keyboard | Phone |
|---|---|---|
| Drive / walk | W A S D or arrows | GAS / WALK, arrows |
| Run | Shift + W | Hold WALK |
| Look around | Mouse (Esc frees it) | Drag on the screen |
| Jump / handbrake | Space | JUMP / H-BRAKE |
| Talk, get in, enter | E | Action button |
| Get out, leave, end chat | Q | Action button / BYE |
| Horn | H | HORN |

## Notes
- Typing free-form messages to the gang only works when the game is opened inside Claude; on GitHub Pages the quick-reply buttons still work.
- Settings and your #49 setup are saved in your browser.
